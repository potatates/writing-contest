# Thanks for Not Choosing Me

Responsive writing-contest website for InkPort, RocNovel, and SuperStory. Includes the contest calendar, rules, prizes, and 20 illustrated inspiration prompts.

## Preview

Open `index.html` in a browser, or serve this folder with a static web server. No build step or dependencies are required.

## GitHub Pages

In repository Settings → Pages, select deployment from the `main` branch and `/ (root)`. Keep `index.html`, `romance.css`, and `assets/` together.

## Assets

The banner, prompt illustrations, and award artwork were generated for this site. Award artwork uses transparent WebP images. The site uses relative asset paths to support GitHub Pages project URLs.
